# 分级特征定义
> 本文件定义"设备类型 → 场景 → 特性"三层特征的判定标准


## 设备类型层级判定标准(按序判定)
1. 算子文档中是否存在了`## 产品支持情况`/ `支持的产品型号`等章节，或名称语义与示例高度相似的章节，章节中是否以表格或分条列出的形式指定了算子的设备支持情况，存在需要进行`设备类型`提取；
2. 如果1的条件不符合，则搜索是否在算子文档中文中以文字形式显示明确标注该算子支持的设备类型，如: `该算子支持Atlas A3 训练系列产品`或`不支持Atlas 350 加速卡`；


## 场景层级判定标准(按序判定)
1. 算子文档中触发了`场景模板关键词`中的关键词，如果命中，将此关键词作为场景层的名称；
2. 文档中是否使用表格/分条列出的形式罗列所有支持的场景；
2. 算子文档中是否显示存在多个场景的区分描述，每个场景以一个小章节描述，如：`**量化场景（静态量化，无perTokenScaleOptional）：**`章节； 
3. 算子文档是否在正文中详细描述了不同场景的区别，如：`xx场景下，支持xx特性，需要满足如下条件...`等相似含义的描述，必须是明确标注不同场景有不同的处理逻辑； 
4. 文档含量化参数信号（`quantMode`/ `gmmXQuantMode`/`antiquantMode`/位宽表达式等 
5. 文档中"公共约束/公共说明"等设备组级别的通用约束说明，不作为场景类别输出；
6. 禁止仅以**场景**二字是否出现作为提取的判别标准；

## 特性参数判定标准(按序判定)
1. 文档中明确以一个章节介绍特性参数，如章节标题为`### 特性参数组`或`xx特性参数组`等，或相似的特性描述章节，搜索是否有参数可以直接影响特性组的选择，如果存在，则需要特性参数的提取； 
2. 算子参数的不同取值或参数属性的不同取值(参数属性包括：参数数据类型、参数数据格式、参数shape，参数shape长度等)会明确划分不同测试场景或决定某个特性的开启与关闭，则需要进行特性参数的提取；
3. 参数取值可枚举/可离散化/可分不同档位，且存在参数的可选项个数大于1，小于10，则需要进行特性参数的提取。
