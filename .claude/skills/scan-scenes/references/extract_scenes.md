# 算子场景提取
> 本规则供 SKILL M3 第三步引用。目标:从文档中提取**支持的**场景名称
> 样例数据作为参考，**禁止把形态清单当作穷举**。

## 前置条件
- 加载`leveled_feature_definition.md`文件

## 提取规则(逐条执行)
- R1 **场景名称命中场景模板**：算子文档中触发了`leveled_feature_definition.md`中`场景模板`中的关键词，将命中的关键词作为场景名称；
- R2 **表格形式列出场景**：文档中以表格的形式列出所有支持的场景，如`场景速查表`，则提取表格中的所有场景名称,场景名称提取优先按照R5提取，如果不符合R5的规则，按照R6的规则提取；
- R3 **计算公式区分场景**：算子文档中计算公式章节，对于不同的场景，明确表示使用不同的计算公式，则需要提取不同的场景名称，如：`计算公式：
非量化场景：xxx
量化场景（无perTokenScaleOptional）：xxx`,场景名称提取优先按照R5提取，如果不符合R5的规则，按照R6的规则提取;
- R4 **约束说明区分场景**：算子文档的约束说明章节中，区分不同的场景，每个场景都有各自的参数约束条件，则分别提取每个场景的名称，场景名称提取优先按照R5提取，如果不符合R5的规则，按照R6的规则提取;
- R5 **场景名称提取规则**：在提取场景名称时，如果场景名是以场景大类+多模式的方式提供的，需要将场景类+模式的每个组合作为场景名称，如`动态量化（T-T/T-C/K-T/K-C）` 需要拆分为4个场景： [`动态量化T-T`, `动态量化T-C`,`动态量化K-T`,`动态量化K-C`]，如果不是场景组合的方式提供，则按原文输出；
- R6 **场景名称推导规则**：部分文档中的场景模式通过文档内容，或参数属性配置推导而来，目前仅支持量化场景的推导，推导规则参考`参考资料`中的`量化模式推导步骤`，其他场景禁止私自推导，按照原文输出；
- R7 **分类词不作为模板**：概括性分类术语（如`该算子支持 K-C 量化和 mx 量化模式`中的`量化模式`）只是上级分类名，不提取为与模板平级的条目；其下通用说明、参数约束按归属拆分并入分类下各真实场景模板;
- R8 **过期数据过滤**：版本演进等历史章节中出现的模式命名，不作为命名与拆分依据，以场景速查表/约束小节/计算公式等正文为准；
- R9 **预防场景提取单一**：上述规则中的示例数据仅供参考，禁止仅将`量化`作为场景提取关键词提取场景。

## 参考资料
1. 量化专业术语

| 术语 | 简要说明                                                           |
|------|----------------------------------------------------------------|
| 非量化 | 左矩阵和右矩阵均为浮点类型直接计算                                              |
| 全量化 | 左矩阵和右矩阵均为低精度计算，通过scale还原                                       |
| 伪量化 | 对右矩阵权重进行量化，包括perchannel量化模式                                    |
| pertensor | 简称T量化，每个Tensor共用一个相同的量化参数                                      |
| perchannel | 简称C量化，量化对象是右矩阵，每个channel分别使用独立的量化参数                            |
| pertoken | 简称K量化，量化对象是左矩阵，每个token分别使用独立的量化参数                              |
| pergroup | 简称G量化，在reduce轴上对数据分组，每组使用独立的量化参数                               |
| perblock | 简称B量化，在所有轴上对数据分块，每块使用独立的量化参数                                   |
| T-C | 左矩阵pertensor，右矩阵perchannel                                     |
| T-T | 左矩阵pertensor，右矩阵pertensor                                      |
| K-C | 左矩阵pertoken，右矩阵perchannel                                      |
| K-T | 左矩阵pertoken，右矩阵pertensor                                       |
| G-B | 左矩阵pergroup，右矩阵perblock                                        |
| MX | pergroup-pergroup（G-G）量化模式，量化参数类型为FLOAT8_E8M0，group size为32的特例 |
| ND | 常规连续排布                                                         |
| NZ | [FRACTAL_NZ](../../../docs/zh/context/data_format.md)格式（亲和排布）  |
